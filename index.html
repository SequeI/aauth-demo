nono + Aauth

A self-hosted agent identity for signed outbound API requests.

Sandboxed app → nono proxy → signed HTTPS request → API

nono holds the private key on the host, issues a one-hour agent token, and signs allowed requests. The API discovers the public key through the issuer metadata and verifies the token and request.
